# نوالتي — دفتر حسابات تجارة وتصنيع الخرشوف

نظام لصاحب النوالة: الجلابة (بالكوز أو الطن)، الرصيف، النوالات (هارت / كاسات / حشو)، التخريط (قطع / قرص / شرايح / حدوة)، الأنفار، المبيعات للمصانع، العدة، والتسعير الأسبوعي.

- **الموقع:** https://mahmoudaburizk.github.io/nawalty-site/ — بيشتغل من غير نت بعد أول فتحة، والبيانات بتتحفظ على الجهاز.
- **النسخة الاحتياطية:** من «الإعدادات والنسخ الاحتياطي» — نزّل نسخة كل أسبوع.

## للتطوير
| الملف | إيه هو |
| --- | --- |
| `src/nawalty.html` | الكود الأصلي (React + Tailwind من CDN) — بيفتح مباشرة في المتصفح للتجربة |
| `index.html` | النسخة المتجمّعة (من غير نت، الخطوط والمكتبات جواها) — دي اللي على الموقع |
| `tests/calc.test.mjs` | اختبارات الحسابات (الأسعار، الأرصدة، الأسابيع) |
| `tools/build.mjs` | بيبني `dist/index.html` من `src/nawalty.html` |

```bash
npm install
npm test          # اختبارات الحسابات
npm run build     # dist/index.html  ← انسخه للـ index.html في الجذر
```

كود الحسابات كله بين `CALC-START` و`CALC-END` في `src/nawalty.html`، وده اللي الاختبارات بتشغله.
